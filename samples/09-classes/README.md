# 第9章のサンプルコード

.NET 10 / C# 14用。

| プロジェクト | 内容 |
| --- | --- |
| Chapter09_Classes | ID・タイトル・完了状態を持つ通常の完成例 |
| Chapter09_SeparateFiles | 期限を追加し、TodoItem.csとProgram.csへ分けた完成例 |
| AiClassReview/Chapter09_ClassReview | 意図的に問題を含むAIレビュー演習版 |
| AiClassReview/Chapter09_Corrected | 演習版のID変更範囲と完了処理を修正した例 |

本文ではChapter09_Classesをそのままファイル分割します。Chapter09_SeparateFilesは、分割後の状態を別途保存したサンプルです。

AI演習版は完成例ではありません。Completeがfalseを設定する問題と、作成後にIDを書き換えられる問題を含めています。private setやリスト要素の参照共有、タイトルの変更は正しい処理として残します。
